## Guiding Principles

- Consistency > intensity
- **Weight loss is the force multiplier** — every pound off is free FTP (w/kg) and free run pace (pace-at-HR)
- Never sacrifice recovery for short-term gains
- Train like an athlete, not like you're dieting
- Build in phases, not randomly — **seasonality gets us there; not everything before Jan 1**
- Pre-load before big efforts. Fuel the work.
- **Anchor the *intentional* workouts to tested numbers, not inferred ones.** ~80% of training stays aerobic-by-feel (Z2 rides, HR<140 runs) — no lab precision needed. But the quality sessions (bike over-unders/threshold, run tempo/threshold/intervals) get real targets off actual tests.
- Ride by HR *and now power* — testing gives us both anchors instead of guessing.

## Threshold Testing Protocol (NEW — Jul 15, 2026)

**Why:** the 217 FTP was a one-off pre-coaching Zwift ramp; everything since (230→210) was inferred off race data and one fatigued free-ride. Run LTHR has never been tested; run "tempo pace" is a couple of observed points. We've been prescribing quality work off guesses. Fix it.

**Tests:**

| Test | Sets | Protocol |
|------|------|----------|
| **Bike ramp** (Zwift built-in) | FTP baseline + comparison to the original 217 ramp | Standard Zwift Ramp Test. Ramp tends to read *higher* for punchy/anaerobic riders — a useful physiology read. |
| **Bike 20-min** (Zwift built-in) | FTP for sustainable zones **+** bike LTHR | ~2 weeks after the ramp. The more conservative, "trainable" number. **Compare vs the ramp:** ramp ≫ 20-min = punchy/anaerobic; close = steady diesel. |
| **Run 5K time trial** | **VDOT → all run paces** (Easy/Marathon/Threshold/Interval/Rep) + run LTHR + a current half-marathon prediction | All-out, even effort, on a **flat measured course or track** (not trails — GPS on rolling terrain muddies pace). Warm up 10–15 min + strides. |

**VDOT note:** Jack Daniels' system — one all-out effort → a fitness number → every training pace *and* equivalent race times across distances. The 5K instantly predicts the current half time, so we'll know day-one how far sub-2:00 really is.

**Cadence:** re-test every **6–8 weeks** and after meaningful weight loss (zones drift as you get fitter *and* lighter).

**Testing window:** **week of Aug 3** (back from camping, fresh). Run 5K TT first (priority goal, needs freshest legs) → bike ramp ~3–4 days later → 20-min bike ~2 weeks after the ramp. Structured block starts fully calibrated ~week of Aug 10.

## Weight Strategy

- **Ultimate target:** 165 lbs. **Interim:** ~175 by late fall.
- **Rate:** 0.5–0.75 lb/week. Trending down is the win; the pace is the success metric, 165 is the destination (no hard deadline).
- **Reality check (Jul 15):** ~6 lbs off in 6.5 months (~0.2/wk actual) and flat ~5 weeks — running at ~⅓ of target. The FBG/BR100 carb-heavy builds are the proximate cause. **Post-relay this becomes the priority lever again.**
- **Calorie approach:** tiered by day type — rest ~2,000–2,200 / light ~2,200–2,400 / hard-long ~2,600+ / event day = match burn, no deficit / pre-race ~2,500+ & 300g+ carbs.
- **Protein: 150g/day** (whey scoop is the key lever — light on non-run days is the recurring miss).
- No aggressive dieting during race weeks. Carbs aligned to training days.
- **On-bike fueling:** validated 80–106 g/hr with SiS + Tailwind; FBG ran 83.7 g/hr clean.

## Avoid

- Skipping fueling during long efforts
