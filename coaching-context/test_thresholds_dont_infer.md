Roger flagged (Jul 15, 2026) that the coach's real gap has been **prescribing quality workouts off inferred zones instead of tested ones.** Symptom: the FTP number bounced 217→230→210 because the 217 was a one-off pre-coaching Zwift ramp and everything since was inferred off race data + one fatigued free-ride. Bike LTHR was literally labeled "inferred"; run LTHR was never tested; run "tempo pace" was a couple observed points.

**Why:** you can't be intentional about threshold/over-under/tempo/interval sessions if the target intensity is a guess. Aerobic-by-feel work (Z2 rides, HR<140 runs — ~80% of training) doesn't need this. The *quality* sessions do.

**How to apply:**
- Set quality-workout zones off actual tests: **bike ramp + 20-min FTP** (Zwift built-in; do both ~2 wks apart and compare — ramp≫20min = punchy/anaerobic, close = diesel), **run 5K time trial → VDOT** (flat/track, all-out even effort → every training pace + run LTHR + a half-marathon prediction).
- **Re-test every 6–8 weeks** and after meaningful weight loss (zones drift as he gets fitter AND lighter).
- Don't over-test — test to set/re-anchor zones, not constantly.
- First testing window executed week of Aug 3, 2026 (bike ramp Aug 5, run 5K TT ~Aug 8). Full protocol lives in `big-picture.md` → "Threshold Testing Protocol".
